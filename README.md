# ERP-Multitenant

Arquitectura base multitenant organizada por giro comercial y gestión de páginas:
- \giros/reparacion_computadoras\
- \giros/restaurante_cafeteria\
- \giros/abarrotes\
- \giros/ferreteria\
- \giros/reparacion_celulares\

## Flujo de ramas
- \main\: versión estable/aprobada.
- \develop\: desarrollo e integración progresiva de módulos.
- \	est\: rama de pruebas antes de regresar/aprobar en \develop\ y \main\.
